Pize es compatible con distintos lenguajes y herramientas de investigación utilizados en análisis de datos, cálculo numérico, aprendizaje automático y visualización. Ofrece asistencia de programación con IA para estos flujos de trabajo; consulta la [documentación oficial](https://pize.ai/docs) para conocer el alcance concreto del soporte.

## <img src="assets/section-icons/research.svg" width="22" height="22" alt="" /> **Para la investigación: completar código, escribirlo y buscar posibles errores**

**Pize es un asistente de programación con IA diseñado para trabajar con código científico y datos estadísticos.** Conecta las distintas etapas: comprender un proyecto, preparar el análisis, escribir y ejecutar código, examinar las salidas y los gráficos, y ajustar el siguiente paso. Puedes usarlo en Pize Code, Positron o la CLI, o integrarlo en tus propios programas mediante el SDK.

Los errores de análisis suelen empezar antes del modelado: un delimitador mal identificado, un valor ausente tratado como un número o una primera observación confundida con la cabecera. Pize da prioridad a comprender los datos, para que el código posterior se apoye en la estructura real de las entradas y no en suposiciones sobre el archivo.

Este repositorio es la página pública del producto y la comunidad de Pize. Lo mantiene su fundador, [@guopengnaivoc](https://github.com/guopengnaivoc).

## <img src="assets/section-icons/features.svg" width="22" height="22" alt="" /> **Cómo te ayuda Pize**

| Capacidad | Aplicación práctica |
| --- | --- |
| **Comprender archivos de datos** | Identificar delimitadores, cabeceras, valores ausentes y tipos de columna a partir del contenido, y tratar comentarios, metadatos y tablas comprimidas. |
| **Aportar contexto sin cargar todo el dataset** | Cuando el archivo supera el presupuesto de contexto, ofrecer una ficha breve con la estructura, una pequeña vista previa y un número de filas claramente identificado como estimación. |
| **Conectarse a una sesión real de R / Python** | En Positron, consultar la sesión actual y resumir dataframes. Con aprobación, ejecutar código y obtener gráficos para seguir trabajando a partir de salidas reales. |
| **Revisar cambios de código** | Coordinar modificaciones entre archivos, examinar diferencias, deshacer cambios y volver a un punto de control anterior de la tarea. |
| **Planificar antes de ejecutar** | Entender primero el proyecto y discutir el plan de análisis; después, escribir código y ejecutar comandos del terminal con aprobación. |
| **Aprovechar el contexto del proyecto y del navegador** | Referenciar archivos, carpetas, problemas y URL, y combinar navegación, capturas de pantalla y registros para investigar errores. |
| **Reutilizar convenciones** | Organizar definiciones estadísticas, criterios para gráficos y estructura de directorios mediante reglas y habilidades del proyecto. |

Para formatos de datos de investigación como Parquet, Arrow, RDS, HDF5, h5ad, NumPy, SPSS y Stata, Pize puede reconocer el formato y ayudar a generar el código de carga adecuado. No significa que todos los formatos binarios se decodifiquen directamente dentro de la conversación. Los detalles y límites se describen en la [documentación de lectura de datos y entorno de ejecución](https://pize.ai/docs).

## <img src="assets/section-icons/interfaces.svg" width="22" height="22" alt="" /> **Trabaja en tu entorno habitual**

| Interfaz | Uso |
| --- | --- |
| **Pize Code** | Comprender proyectos, revisar modificaciones y trabajar en el terminal desde el editor. |
| **Positron** | Usar el mismo asistente conectado a la sesión de R o Python que tienes activa. |
| **CLI** | Utilizar Pize desde la línea de comandos. |
| **SDK** | Integrar el asistente y sus capacidades orientadas a datos en programas propios o herramientas internas. |

El puente con la sesión en ejecución es una capacidad específica de Positron; no todas las interfaces ofrecen el mismo acceso al entorno de ejecución. Consulta la [documentación oficial](https://pize.ai/docs) para la instalación y los detalles de cada opción.

## <img src="assets/section-icons/models.svg" width="22" height="22" alt="" /> **Elección de modelos y conexión de herramientas**

Pize admite conexiones a modelos en la nube y locales, incluidos Anthropic, OpenAI, Google Gemini, DeepSeek, AWS Bedrock y OpenRouter, además de servicios con API compatibles con OpenAI. Elige el modelo y la configuración según tus necesidades de investigación y tu entorno de despliegue.

**El SDK integra Pize en tu programa; MCP lo conecta con herramientas externas.** Como cliente MCP, Pize puede conectarse a bases de datos, sistemas internos y herramientas de laboratorio mediante servidores compatibles. Las operaciones disponibles dependen del servidor y de los permisos que concedas.

## <img src="assets/section-icons/start.svg" width="22" height="22" alt="" /> **Empieza a usar Pize**

1. **Elige el entorno.** Empieza por la [página oficial de descargas](https://pize.ai/download) y sigue las instrucciones de instalación correspondientes.
2. **Configura el modelo.** Sigue la documentación para conectar un servicio compatible o un endpoint local.
3. **Proporciona el contexto de investigación.** Abre el proyecto y adjunta los scripts o datos pertinentes. En Positron, activa la sesión en la que ya están cargados los datos de interés.
4. **Planifica, aprueba y ajusta.** Acuerda el enfoque y revisa las acciones propuestas. Después de ejecutarlas, examina el código, las salidas y los gráficos antes de decidir qué hacer a continuación.

### <img src="assets/section-icons/examples.svg" width="20" height="20" alt="" /> **Preguntas con las que puedes empezar**

Son ejemplos de solicitudes de uso, no resultados de análisis validados de forma independiente.

- «Comprueba primero las columnas, los tipos y los valores ausentes de este dataset y después sugiere un análisis».
- «Explica este proceso de análisis en R o Python y enumera los supuestos que debería revisar».
- «Ayúdame a modificar el script de análisis, ejecútalo tras mi aprobación y explica los resultados con los gráficos de diagnóstico».

Pize ayuda con el trabajo, pero no sustituye el criterio científico. Revisa los supuestos del método y las salidas antes de confiar en un análisis. El tratamiento de los datos depende de las herramientas y servicios de modelos que configures; lee la [información de privacidad](https://pize.ai/privacy) del producto y las políticas del proveedor del modelo.

## <img src="assets/section-icons/repository.svg" width="22" height="22" alt="" /> **Qué se publica en este repositorio**

Este repositorio ofrece información del producto, orientaciones para la comunidad y una [página independiente de visualización interactiva de proteínas](https://guopengnaivoc.github.io/pize.ai/). Se trata de una demostración visual, no de un servicio de predicción de proteínas ni de resultados de investigación validados. Las fuentes de los datos figuran en los [créditos de los recursos de proteínas](assets/protein-CREDITS.md).

**El código fuente de la aplicación principal de Pize no se publica en este repositorio.** Hacer público el visor no convierte todo el producto en código abierto. En el futuro podrán publicarse herramientas, ejemplos y notas técnicas seleccionados por separado, cada uno con su alcance y licencia. El sitio oficial indica cómo obtener el software y su disponibilidad actual.
