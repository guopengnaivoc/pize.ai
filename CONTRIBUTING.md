# Feedback and participation

This repository currently accepts feedback and documentation contributions. Product source code has not been uploaded here.

## Useful feedback

- Describe the research task and the outcome you want.
- For a product problem, state the version and environment if known.
- Explain expected and actual behavior with enough detail to understand the issue.
- Use synthetic inputs and redact private paths or identifying details from logs.
- Link to the exact documentation page when proposing a correction.

Documentation corrections can be proposed in a pull request. Please discuss substantial new material in an issue first, especially if it includes third-party content or data.

Public issues are visible to everyone. Do not include model API keys, account details, patient records, customer files, or unpublished research data. Account questions and collaboration inquiries belong at [pize.ai/contact](https://pize.ai/contact).

Keep discussions specific and respectful. Requests inform future priorities; a request is not a promised feature or delivery date.
