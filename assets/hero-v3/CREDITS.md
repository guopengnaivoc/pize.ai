# Pize.ai 首屏动画素材说明

## 数据与来源

- 结构标识：AF-G1JSI4-F1。
- 蛋白质名称：At1g58602（官网标注为抗病相关蛋白）。
- 结构数据：[AlphaFold Protein Structure Database](https://alphafold.ebi.ac.uk/entry/G1JSI4)，DeepMind / EMBL-EBI。
- 数据许可：[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)。
- 展示来源：[Pize.ai 官网](https://pize.ai/zh-Hans)及其[蛋白质渲染页面](https://pize.ai/digital-protein/canvas-silk2.html)。

## 展示制作

本目录使用创始人确认的 v3 视觉方案，保留官网原版结构配色。蛋白质以 1920 × 1680 像素原生渲染，再缩放并排入 2240 × 840 像素的首屏横幅；不是将低清录像放大。

动画包含完整一圈旋转，共 360 帧，每帧 60 毫秒，周期为 21.6 秒。最后一个重复起始角度的帧不纳入循环。发布的动画 WebP 由已确认的 v3 GIF 以 quality=82 压缩导出，保持原像素分辨率与完整帧序列；不是无损文件。PNG 为静态替代图，原始高清母版保留在本地。

为配合 GitHub 的深浅主题，分别提供 #0d1117 和 #ffffff 背景版本。首屏品牌、文案和构图由 Pize.ai 提供或确认。此处公开的是展示图像，不包含 Pize 核心应用源码、高清录像母版或渲染数据源文件。

该动画仅用于视觉展示，不是蛋白质预测服务，不代表经过验证的科研结果；展示配色不应被当作 pLDDT 或其他置信度标尺。
