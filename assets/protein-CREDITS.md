# Protein visualization and recording credits

The published index.html contains the Canvas visualization and all 12 embedded protein records supplied by Pize's founder. Pize's unrelated product and core application source code are not included.

The original viewer, colors, and rendering controls are retained. All 12 embedded records are enabled. The selected protein keeps rotating, but the page does not automatically switch to another protein. Use the original dropdown or previous/next buttons to choose a different protein.

The README GIFs are recordings of AF-G1JSI4-F1, using the original light and dark themes. They were recorded, resized, palette-converted and GIF-encoded on 2026-09-08. Click the README animation to open the live viewer.
