# Frequently asked questions

## What is Pize?

Pize is an AI coding assistant focused on scientific computing and statistical analysis. The [website](https://pize.ai) introduces the product; its [documentation](https://pize.ai/docs) describes the workflow.

## Is this the product source repository?

No. This is a public product and community hub. It currently contains product information and documentation, not the application's source code or a self-hostable product.

## Where can I download Pize?

Use the [official download page](https://pize.ai/download). Follow the information there for current availability and installation. This GitHub repository does not distribute product binaries at this stage.

## Will code be published later?

Selected tools, examples, or technical materials may be added later. Their scope and license will be stated when they are published. No date or promise to open-source the entire product is implied.

## Who maintains this repository?

Pize's founder maintains it through [@guopengnaivoc](https://github.com/guopengnaivoc), using **pize.ai** as the public name.

## How can I contribute now?

Suggest clearer documentation, describe a useful research workflow, or report a product experience using a synthetic example where possible. See [the feedback guide](../CONTRIBUTING.md).

## How should I share a private product issue?

Use [Pize contact](https://pize.ai/contact) for account questions or to request a suitable private channel. Keep private research data, credentials, and unpublished results out of public GitHub issues. For suspected security problems, initially describe only the general issue and request a private reporting route.

- **这是源码仓库吗？** 当前是产品介绍与交流入口，源码尚未上传。

- **以后会公开代码吗？** 后续可能发布部分工具和示例，届时单独说明范围与许可。
- **由谁维护？** 由 Pize 创始人通过 `@guopengnaivoc` 维护，公开名称为 `pize.ai`。
- **如何联系？** 公开建议使用 Issues；账户问题和合作咨询使用 [官网联系页](https://pize.ai/contact)。
